## Содержание

Здесь — **публичная** справка по темам для администраторов тенанта, которые ведём в репозитории: **HTTP API / интеграции** и **цифровое табло** (плейлисты, расписания, экран).

- **Справка внутри продукта** (`/{locale}/help/...`) — отдельное дерево MDX в приложении.
- **Контракт HTTP** (пути, тела, схемы) — всегда **OpenAPI**, который отдаёт ваш API (например JSON по `/docs/openapi.json` на хосте API).

## Разделы

- [Developer API, вебхуки и публичный виджет очереди](/ru/docs/developer-api) — `planCapabilities`, REST интеграций, вебхуки, embed-виджет.
- [Цифровое табло (экран юнита)](/ru/docs/digital-signage) — плейлисты, расписания, фиды, объявления.

## Scope

This site is the **public** reference for tenant-facing topics we ship as Markdown/MDX from the monorepo. It focuses on **Developer API** (integrations, webhooks, embed) and **Digital Signage** (playlists, schedules, screen).

- **In-product help** for end users lives in the app under `/{locale}/help/...` and is maintained as MDX in the product repo.
- **The HTTP contract** (paths, request/response models) is always the **OpenAPI** document your API serves (e.g. JSON at `/docs/openapi.json` on the API host).

## Pages in this section

- [Developer API, webhooks, and public queue widget](/en/docs/developer-api) — `planCapabilities`, integration REST, webhooks, and the embeddable queue widget.
- [Digital Signage (unit display)](/en/docs/digital-signage) — playlists, schedules, status, and announcements for public screens.
